RAS: remote maintenance without limits

The routers we supply include a connection licence to the M2Me server for a secure VPN connection to the site from the client's computer, tablet or smartphone.

No subscription costs

The M2Me solution has no subscription cost: you pay for the router and that's it.

  • Any number of RAS units can connect to a server — there's no device limit
  • The licence is included in the router's price, with no annual renewal fee
  • Access from PC, tablet or smartphone (iOS/Android) at no extra cost for the client access or the app

Core remote-maintenance features

  • Edit the PLC program
  • Parameterise variable-speed drives
  • Modify the HMI program
  • Monitor equipment behaviour
  • Control machines and processes
  • Access the equipment's webservers

Cybersecurity

  • Every access to the machine is controlled
  • Access via a remote access server (M2Me Server)
  • Requires a security certificate, username and password
  • No ports opened

Value delivered in remote maintenance

  • Greater maintenance efficiency
  • Reduced travel costs
  • Improved flexibility of use
  • Development of remote-control services for machines and lines

Collect&Alert: additional features included by eXDCi Solutions

RAS routers can read information from field equipment via the ModbusTCP or OPC UA protocols. Each unit can communicate up to 128 variables with devices on the LAN, configured without programming through its built-in web server.

Once the data is collected, the RAS router offers several ways to use it:

  • Sending alarms by email or SMS (SMS included at no cost on routers with cellular WAN)
  • Local storage in the router's internal memory, with daily data delivery in CSV format
  • Direct cloud connection: native connectors for Aveva Insight, Store4Me, Siemens Mindsphere and Cumulocity, plus HTTPS and MQTTs compatibility with other systems

Storage capacity and included SMS depend on the router model selected.

A 2-in-1 solution

These features can be switched on from day one or activated later, with full flexibility:

  • Connectable machines: ready to connect at any time via M2Me, with future scalability guaranteed
  • Connected machines: with an active connection and advanced information-system integration features
